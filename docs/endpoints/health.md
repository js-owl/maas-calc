# `GET /health`

## Назначение

Проверка доступности приложения.

## Путь выполнения

1. Запрос попадает в `main.py::health_check`.
2. Формируется `data = {"status": "healthy"}`.
3. Ответ заворачивается через `ResponseWrapper.success_response`.

## Особенности

Эндпойнт не проверяет наличие ML-моделей, приватных справочников `COST_STRUCTURE` / `MACHINES`, доступность CAD-зависимостей или корректность конфигурации материалов. Это только базовая проверка, что FastAPI-приложение отвечает.
